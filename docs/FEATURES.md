# Final Fantasy Resonance Companion Toolkit — feature reference

Use the Final Fantasy Resonance companion toolkit workspace to move between character notes, party profiles, and activity records. The section map below gives each part a clear place in the project.

| Section | Description |
|---|---|
| Character notes | Character-related parameters and the settings associated with the selected category. |
| Party profiles | Related settings collected into named groups for a clearer configuration workflow. |
| Activity records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
